二、分章知识点总结

1. 电介质的极化、电导和损耗

全章围绕“极化—介电常数—电导—损耗”四条主线。四种极化形式的时间尺度、损耗有无、温度/频率依赖是选择题与简答题的高频考点。

知识点核心要点
1.1 电介质的极化去练习 →• 电介质：电阻率很高、能持久建立静电场的物质；按状态分固/液/气，按化学结构分非极性、弱极性、极性、离子性。<br>• 极化定义：外电场作用下，沿电场方向两端出现等量异号电荷（束缚电荷），对外呈现极性。<br>• 电子式极化：电子相对原子核位移，约10^-15 s，存在于一切介质，弹性、无损耗，温度影响小。<br>• 离子式极化：正负离子相对位移，约10^-13 s，弹性、几乎无损耗，温度升高极化增强。<br>• 偶极子（转向）极化：极性分子顺电场转向，10^-10~10^-2 s，有损耗，与温度和频率关系密切。<br>• 空间电荷极化：自由离子/电子移动后在电极或界面堆积；夹层极化属于此类；10^-1 s以上甚至数小时，有损耗。<br>• 极化时间排序：电子式 &lt; 离子式 &lt; 偶极子式 &lt; 空间电荷（夹层）式。
1.2 电介质的介电常数去练习 →• εr = C/C0，极化程度越强εr越大；电容器绝缘希望εr大，电缆绝缘则希望εr小以减小电容电流。<br>• 气体：密度小，工程上εr≈1；随温度升高而下降，随压力增大而增大。<br>• 中性/弱极性液体与固体：只有电子式、离子式极化，εr较小，变化规律与密度随温度变化一致。<br>• 极性液体与固体：εr较大；低温时随温度升高而上升，温度继续升高则下降；频率越高εr越小（夹层、转向极化跟不上）。
1.3 电介质的电导去练习 →• 电导来源于介质内少量自由带电质点的定向运动，分离子电导与电子电导；固体、液体通常以离子电导为主。<br>• 出现大量电子电导意味着碰撞电离、介质已被击穿；气体中可存在电子式电导。<br>• 液体电导：离子电导（分子/杂质离解）+ 电泳电导（胶体吸附电荷）；温度升高、场强超过临界值后电导急剧增大。<br>• 固体电导：体积电导（纯度与极性决定）+ 表面电导（水分和污物决定，亲水性物质表面电导更大）。<br>• 温度越高、杂质越多，固体电导越大；绝缘电阻是电导的倒数，通常指体绝缘电阻。
1.4 电介质中的能量损耗去练习 →• 介质损耗由电导损耗与极化损耗（偶极子转向、夹层极化等）组成。<br>• 交流下电流分为有功与无功分量；tanδ = 有功分量/无功分量，只取决于材料特性，与尺寸无关，是判断介质品质的指标。<br>• 等值电路：电导损耗为主用并联等值电路；极化及引线电阻损耗为主用串联等值电路；一般情况可用三支路等值回路。<br>• 气体：电压升高tanδ增大，超过电晕起始电压后急剧增加。<br>• 中性/弱极性介质：损耗主要来自电导，较小，温度规律与电导类似。<br>• 极性介质：tanδ随温度呈“低—峰—谷—再升”四段变化；频率升高时极化减弱，tanδ总体减小。

2. 气体电介质的电气特性

本章是全书核心：带电质点产生与消失、汤逊与流注理论、极性效应、伏秒特性、沿面放电及提高击穿电压的措施。公式图片有丢失，见文末存疑清单。

知识点核心要点
2.1.1 气体中带电质点的产生和消失去练习 →• 基本概念：击穿（破坏性放电）、火花放电、电弧放电（电源功率大、内阻小）、局部放电、闪络（沿固体表面）。固体击穿永久丧失绝缘强度，气体/液体一般只暂时丧失。<br>• 带电质点来源：气体分子本身电离（碰撞电离、光电离、热电离）+ 金属电极表面电离。<br>• 碰撞电离主要靠电子（自由行程长）；光电离条件是光子能量不小于电离能；热电离是高温下碰撞与热辐射的综合。<br>• 表面电离四种：热电子发射、强场发射（约10^6 V/cm，冷发射）、正离子撞击阴极（二次发射）、光电效应。金属逸出功远小于气体电离能，故表面电离很重要。<br>• 负离子形成：电负性大的气体（如SF6）易吸附电子形成负离子，减少自由电子，抑制放电、提高耐电强度。<br>• 带电质点消失：到达电极中和、扩散、复合；复合有时因产生光辐射而促进放电。
2.1.2 气体放电机理去练习 →• 电场不均匀系数 f = 最大场强/平均场强；f=1均匀，f≤2稍不均匀，f&gt;2极不均匀。<br>• δd较小时适用汤逊理论与巴申定律；δd较大时适用流注理论（课件中的“6.5px”为丢失公式，见存疑表）。<br>• 均匀电场I-U曲线：0-a电流随电压升高；a-b电流饱和；b-c碰撞电离引发自持放电（电子崩）。电子数按2^n增长，电子在崩头，崩体主要是正离子。<br>• 汤逊理论：低气压短间隙；依靠电子碰撞电离（α过程）与正离子撞击阴极产生二次电子（γ过程）；不能解释放电时间短、与阴极材料无关、有分支细通道等现象。<br>• 流注理论：高气压长间隙；空间电荷畸变电场 + 光电离产生二次电子崩，与主崩汇合形成流注通道。巴申定律是汤逊理论的实验证明。<br>• 放电形式发展顺序：辉光 → 电晕 → 刷状 → 火花 → 电弧。
2.1.3 电晕放电去练习 →• 电晕：极不均匀电场中曲率半径小的电极附近强场区出现自持放电，伴随蓝紫色晕光。<br>• 电晕放电是极不均匀电场特有的自持放电形式；能否出现稳定电晕是区分极不均匀与稍不均匀电场的标志。<br>• 条件：极间距离与起晕电极最小曲率半径之比大于一定值；否则直接火花击穿。<br>• 形式：低电压时电子崩型（均匀稳定），高电压时流注型（不均匀、不稳定、有脉冲）。<br>• 极性效应：负电晕的规则重复电流脉冲机制比正电晕强。<br>• 效应：噪声与温升、高频脉冲电流干扰无线电、化学效应（臭氧等）、“电风”。<br>• 输电线路：增大导线半径或采用分裂导线可降低表面场强、减少电晕损耗；雨雾霜雪等坏天气使电晕损耗急剧增加。
2.1.4 不均匀电场气隙的击穿（极性效应）去练习 →• 极性效应：极不对称电场中，棒极极性不同导致起晕电压和击穿电压不同，根源是空间电荷对外电场的畸变。<br>• 正棒—负板：棒附近正空间电荷削弱棒极场强 → 起晕电压高；板极附近场强加强 → 击穿电压低。<br>• 负棒—正板：棒附近正空间电荷加强棒极场强 → 起晕电压低；板极附近削弱 → 击穿电压高。口诀：正棒“难起晕、易击穿”。<br>• 短气隙（d≤1 m）以流注方式发展；长气隙以先导方式发展。<br>• 先导过程：流注 → 先导（通道温度约10^4 K，发生热电离）→ 主放电通道 → 击穿；离子浓度：主放电通道 &gt; 先导 &gt; 流注。<br>• 负先导接近板极时，由板极发出迎面（正）先导，因正先导比负先导更易发展。
2.1.5 气隙的沿面放电去练习 →• 沿面放电：沿固体（或液体）与气体分界面发展的放电；发展到对面电极称沿面闪络。同距离下闪络电压低于纯气隙击穿电压。<br>• 均匀电场中沿面闪络偏低的四原因：电极与介质间微小气隙、表面水膜、表面粗糙、表面电阻不均匀。<br>• 强垂直（法线）分量电场（套管）：电晕 → 刷形放电 → 滑闪放电（热电离通道，类似先导）→ 沿面闪络；频率越高、G/C越大越易滑闪。<br>• 弱法线分量、强切线分量（支柱绝缘子）：不易形成滑闪，闪络电压也不会显著降低。<br>• 干闪（干燥洁净表面）、湿闪（洁净表面淋雨，需形成烘干区，雷电冲击下来不及形成）、污闪（脏污受潮，污层电导率、等值盐密度、爬电比距表征）。<br>• 影响沿面闪络电压：介质吸湿性（相对湿度&gt;50%~60%后明显下降）、电压种类（工频最低，冲击较高）、介质与电极结合紧密程度、空气干燥程度。<br>• 提高方法：屏障（伞裙）、屏蔽（均匀电位）、加电容极板、消除窄气隙、憎水涂料、半导体漆、固定沿面电位、均压环、合成/半导体釉绝缘子。
2.2.1 气隙的击穿时间去练习 →• 气体电气强度由击穿电压、击穿场强、击穿时间共同体现。<br>• 击穿时间 t = 升压时间 t1 + 统计时延 ts + 放电形成时延 tf。
2.2.2 伏秒特性与冲击波形去练习 →• 标准雷电冲击波：T1=1.2 μs（±30%），T2=50 μs（±20%）；标准操作冲击波：Tp=250 μs（±20%），T2=2500 μs（±60%）。<br>• 伏秒特性：波形不变、幅值不同时，击穿电压与击穿时间的对应关系；因放电时间分散，实际为上下包络线间的带状区域，常用50%伏秒特性。<br>• 均匀/稍不均匀电场：伏秒特性仅在短时区域左上翘，右边平坦；极不均匀电场：整体上翘。<br>• 绝缘配合要求：避雷器的伏秒特性必须位于被保护设备伏秒特性下方。<br>• 50%击穿电压：击穿概率为50%时的冲击电压峰值，只是50%伏秒特性上的一点，不能全面反映冲击击穿特性。
2.2.3 大气条件的影响去练习 →• 外绝缘破坏性放电电压 U = U0·kT，其中大气校正因数 kT = kd（空气密度）× kh（空气湿度）。
2.2.4 均匀与稍不均匀电场的击穿电压去练习 →• 均匀与稍不均匀电场中，击穿电压与所加电压波形几乎无关，只要达到静态击穿电压即发生击穿。
2.2.5 极不均匀电场的击穿电压去练习 →• 正极性操作冲击U50%均低于负极性，正极性更危险。<br>• U50%随波前时间呈U形曲线：存在临界波前时间与临界击穿电压；左侧因放电时延、右侧因空间电荷改善电场分布而使击穿电压升高。<br>• 操作冲击下U50%分散性比雷电冲击大得多；间隙长度超过约5 m后出现明显饱和现象；极性效应显著。
2.2.6 提高气隙击穿电压的方法去练习 →• 两条主要途径：改善电场分布使其均匀；改变气体状态与种类以削弱电离。<br>• 改善电场：改变电极形状（增大曲率半径、笼形/环形/多重屏蔽）、利用电晕空间电荷（细线效应，仅持续电压有效）、设置屏障。<br>• 屏障：阻挡空间电荷以改变电场分布，持续电压下最佳位置 d1/d≈0.2；雷电冲击下也有效但幅度较小。<br>• 增高气压：电子自由行程减小、不易积累电离动能；1~2 MPa内遵循巴申定律，之后趋于饱和。<br>• 气压越高，电极表面粗糙度、面积效应（面积越大击穿电压越低）与击穿分散性影响越显著；可采用SF6等高耐电强度气体。

3. 液体和固体介质的电气特性

固体三种击穿机理与影响因素、液体“小桥”理论、两类介质提高击穿电压的方法是本章主线。

知识点核心要点
3.1.1 固体电介质击穿的机理去练习 →• 电击穿：带电质点碰撞电离产生电子崩；击穿电压高、时间短、击穿前不发热，与电场均匀度有关、与环境无关。<br>• 热击穿：介质损耗发热 → 温升 → 局部放电 → 丧失绝缘；击穿电压低、时间长、击穿前发热，与作用时间、温度、散热有关。<br>• 电化学击穿：长期加电压导致介质劣化，击穿场强下降；击穿电压低于热击穿，时间可达数月数年。<br>• 时间关系：电击穿 &lt; 热击穿 &lt; 电化学击穿。
3.1.2 影响固体击穿电压的因素去练习 →• 电压作用时间：0.1 s以下多为电击穿；几分钟至数十小时为热击穿；数十小时至若干年为电化学击穿。<br>• 温度升高易发生热击穿；介质越厚、电场越不均匀越易热击穿。<br>• 电压种类：冲击 &gt; 直流 &gt; 交流；交流频率越高，发热越严重，击穿电压越低。<br>• 其他：受潮程度、机械力、多层性。<br>• 累积效应：幅值较低或时间短的冲击反复作用造成不完全击穿逐步延伸，击穿电压随加压次数增加而下降。
3.1.3 提高固体击穿电压的方法去练习 →• 改进绝缘设计：合理绝缘结构（组合绝缘）、改善电极形状、改善电极与绝缘体接触条件。<br>• 改进制造工艺：尽可能消除杂质、水分。<br>• 改善运行条件：注意防潮。
3.1.4 固体电介质的老化去练习 →• 老化：长期运行中发生物理化学变化，电气与机械强度降低、介质损耗和电导增大。<br>• 局部放电老化机理：带电粒子撞击使主链断裂、局部高温化学分解、活性气体氧化腐蚀、紫外线/软X射线导致分解。<br>• 热老化：长期受热性能劣化；按最高容许温度划分绝缘耐热等级。<br>• 受潮老化：水分侵入或热氧化生成，导致电导与损耗增大，加速发热与热老化。
3.2.1 液体电介质击穿的机理去练习 →• 纯净液体：电击穿（阴极强场发射 → 碰撞电离 → 正电荷加强强场发射）与气泡击穿；电击穿电压高于气体。<br>• 气泡击穿：气泡ε小于液体 → 气泡承受较高场强 → 先电离 → 温度升高 → 液体汽化形成气泡通道 → 击穿；击穿电压较高、时间较长。<br>• 工程用液体：杂质（气体、纤维、水分）极化后首尾相连形成“小桥”，泄漏电流增大、发热汽化产生气泡，导致击穿；击穿电压低于纯净液体。
3.2.2 影响液体击穿电压的因素去练习 →• 杂质：悬浮态水影响最大（溶解态、悬浮态、沉淀态），纤维易成桥，含气量易气泡击穿，含碳量有双面作用。<br>• 温度：0~80 ℃内击穿电压随温度升高而上升（水分充分溶解）；更高温度水分汽化使击穿电压下降；低于0 ℃先降后升（悬浮水结冰、密度增大）。<br>• 电压作用时间：形成小桥比气体放电慢，故冲击击穿电压远高于工频。<br>• 电场均匀程度：纯净液体电场越均匀击穿电压越高；工程用液体相反（不均匀场中局部放电扰动使小桥不易排成）。<br>• 压强越大，气体被排除，击穿电压越高。
3.2.3 提高液体击穿电压的方法去练习 →• 提高并保持液体品质：压力过滤法、真空喷雾法、吸附剂法。<br>• 覆盖（零点几毫米）：阻止杂质与电极接触、抑制小桥；油质越差、电场越均匀、作用时间越长，效果越明显。<br>• 绝缘层（几毫米到几十毫米）：用于不均匀电场，包在小曲率半径电极上，相当于加厚覆盖。<br>• 极间障：液体绝缘板机械阻隔小桥，面积应足够大，距小曲率电极约0.2倍间隙距离时最佳，不能太厚。
3.2.4 液体电介质的老化去练习 →• 课件仅注明“对照教材内容自学，作为了解内容”，需自行补充教材相关段落。

4. 电气设备绝缘试验

预防性试验（绝缘电阻、泄漏电流、tanδ、局部放电）与破坏性试验（工频、直流、冲击高压）的原理、接线、优缺点是高频考点。

知识点核心要点
4.1.1 测定绝缘电阻去练习 →• 兆欧表：直流电源（手摇发电机/整流）+ 电压线圈LV与电流线圈LA，利用转动力矩平衡测量；L线路端、E接地端、G屏蔽端。<br>• 直流加压后吸收电流需衰减，一般加压60 s后读数作为绝缘电阻。<br>• 吸收比 K = R60s / R15s，反映吸收电流引起的过渡过程；极化指数 PI = R10min / R1min。<br>• 优点：简便、能发现整体受潮与贯穿性缺陷；缺点：电压低，不能发现局部损伤、裂缝、分层、内部气隙等局部缺陷。<br>• 注意：测量前断电、充分放电；记录温度并换算；G端屏蔽表面泄漏；吸收比与被试品尺寸无关。
4.1.2 测定泄漏电流去练习 →• 泄漏电流：绝缘两端加足够电压时流过的微小电流（通常以μA计）；比兆欧表电压高，能发现尚未贯通两极的集中性缺陷。<br>• 直流电源要求：电压较高但不过高、负极性（更易发现受潮缺陷）、连续可调、脉动系数≤3%、有保护电阻（常用水电阻）。<br>• 回路元件：试验变压器、高压硅堆整流、滤波电容、保护电阻、微安表、被试品。<br>• 微安表位于高压端：测量准确、接线简单，但需良好屏蔽、不易读数、表头易极化；位于低压端：读数方便但受杂散电流影响。
4.1.3 测定介质损耗因数去练习 →• tanδ = 交流下有功电流/无功电流分量，反映电导损耗、极化损耗和局部放电损耗，只取决于材料。<br>• 测量方法：平衡电桥法（QS1/QS3西林电桥）、不平衡电桥法（M型介损仪）、瓦特表法、相敏电路法。<br>• 西林电桥接线：正接线（桥体低电位、试品两端对地绝缘，准确度高、抗干扰强）、反接线（试品一端接地，适合现场，抗干扰弱）、侧接线、低压接线。<br>• 干扰来源：高压电源对桥体杂散电容、外界电场、外界磁场；消除措施：提高试验电压、尽量采用正接线、屏蔽与倒相。
4.1.4 局部放电的测试去练习 →• 局部放电：绝缘内部异物或气隙处场强超过电离场强而发生局部电离，不立即形成贯穿通道。<br>• 外部现象：电脉冲、介损增大、电磁辐射；光、热、噪声、气体压力与化学变化。<br>• 检测方法：脉冲电流法（最普遍，测视在放电量）、介质损耗法、超声波法、气相色谱法（DGA）、光测法。<br>• 实际放电量难以直接测量，通过等值电路换算得到视在放电量，二者成比例但视在放电量小得多。<br>• 脉冲电流法分直接法（串联/并联）与平衡法（抗干扰好）；直接法灵敏度高但抗干扰差。
4.2.1 工频高压试验去练习 →• 交流耐压包括工频耐压、感应耐压、冲击耐压；工频耐压只考核主绝缘，感应耐压还能考核纵绝缘。<br>• 工频耐压：规定工频电压保持一定时间，一般1 min；适用于不高于220 kV设备，≥330 kV改用操作波耐压。<br>• 属破坏性试验，必须在非破坏性试验全部合格后进行；需正确选择试验电压标准与耐压时间。<br>• 设备：调压器（自耦、移圈、电动发电机组）、高压试验变压器（容量不大、电压高、允许持续工作时间短）、保护电阻。<br>• 试验变压器按被试品电容量与最高试验电压选择额定电流与容量；测量可用球隙、静电电压表、分压器、测量绕组。
4.2.2 直流高压试验去练习 →• 大电容设备（长电缆、电力电容器）用工频交流试验需很大容量，故改用直流耐压，可与泄漏电流测量同步进行。<br>• 产生方式：工频高压经高压整流（半波、桥式全波）；倍压整流可获得2~3 Um，常用负极性倍压回路。<br>• 保护电阻Rb防过电流，限流电阻Rf限制被试品击穿时电容放电电流；高压硅堆关键参数为额定整流电流与额定反峰值电压。
4.2.3 冲击高压试验去练习 →• 冲击耐压检验设备对雷电冲击与操作冲击的耐受能力；一般在制造厂型式/出厂试验进行，运行部门常用1 min工频耐压近似替代。<br>• 超高压设备普遍认为不能用工频耐压代替操作冲击耐压，应进行操作冲击耐压试验。<br>• 冲击发生器：电容器经球隙对RC回路放电形成波前与波尾；C1≫C2、R2≫R1可获得所需短波前。<br>• 球隙测量峰值：球径较小时需用短波光源照射以稳定放电电压。

5. 输电线路和绕组中的波过程

行波传播、折射反射与变压器绕组电位分布是过电压保护的理论基础，公式图片丢失较多，按概念掌握。

知识点核心要点
5.1 波沿均匀无损耗单导线的传播去练习 →• 分布参数处理：导线电压电流不仅随时间变化，也随空间位置变化；均匀无损线忽略电阻、地电阻与漏导，用单位长度L0、C0表示。<br>• 波动方程通解由前行波与反行波叠加：u = uq(x-vt) + uf(x+vt)。<br>• 波速 v = 1/√(L0C0)，波阻抗 Z = √(L0/C0)（课件公式丢失，常见值见速记表）。<br>• 电压前行波与电流前行波同极性，比值为+Z；反行波极性相反，比值为-Z。<br>• 波阻抗只与单位长度参数有关、与长度无关；它贮藏能量而不消耗能量，与电阻本质不同；同时存在前行与反行波时，u/i不再等于Z。<br>• 能量关系：电压波对应电容中的电场能，电流波对应电感中的磁场能。
5.2 行波的折射和反射去练习 →• 不同波阻抗导线的连接点称为结点；行波到达结点因能量重新分配而发生反射与折射。<br>• 折射系数 α = 2Z2/(Z1+Z2)，反射系数 β = (Z2−Z1)/(Z1+Z2)（课件公式丢失）。<br>• 彼得逊等效电路：结点左侧用等值电压源2u1q与内阻Z1，右侧用数值等于Z2的电阻替代。<br>• 末端开路（Z2→∞）：β=+1，末端电压加倍、电流为零；末端短路（Z2=0）：β=−1，末端电流加倍、电压为零。<br>• 行波通过串联电感或旁过并联电容时，由于电感电流、电容电压不能突变，折射系数随时间变化，波被拉平、陡度降低。<br>• Z1较小时宜用串联电感，Z1较大时（如发电机）宜用并联电容降低入侵波陡度。
5.3 变压器绕组中的波过程去练习 →• 绕组简化等值电路由单位长度自感L0、对地电容C0、匝间电容K0组成。<br>• 冲击波刚作用（t=0）电感相当于开路，初始电位按电容链分布：末端开路呈双曲余弦、末端短路呈双曲正弦；首端附近电位梯度最大。<br>• 变压器可用集中入口电容表示其对波过程的影响，入口电容为从首端看进去的等效电容。<br>• 稳态分布：末端短路时按电阻均匀分布，末端开路时各点对地电压相同。<br>• 初始分布与稳态分布不同引起振荡过程，各点最大对地电压连成最大电位包络线；末端短路时最大电位在首端，末端开路时在末端。<br>• 改善方法：在首端加装电容环、电容匝以增大纵电容（匝间电容），相对减小对地电容分流，使电位分布均匀；配避雷器限制侵入波。

6. 输电线路、变电所和旋转电机的防雷保护

雷电参数、避雷针（线）与避雷器原理、线路耐雷水平与防雷措施、变电所进线段保护是核心。

知识点核心要点
6.1 雷电放电及防雷保护装置去练习 →• 雷电流三参数：幅值、波前时间、半峰值时间；平均陡度由幅值与波头决定，对过电压影响大；我国防雷计算采用2.6/50 μs波形。<br>• 避雷针（线）原理：顶端场强集中引导雷电先导向自身放电，经引线与接地装置入地；保护范围用折线法计算。<br>• 保护角：避雷线与外侧导线连线和避雷线对地垂线之间的夹角；保护角越小雷击导线概率越小，通常取15°~30°。<br>• 避雷器类型：保护间隙、管型避雷器（配电与进线段）、阀型避雷器（变电所、发电厂）、氧化锌避雷器。<br>• 阀型避雷器：火花间隙 + 非线性电阻阀片串联；阀片电流越大电阻越小，工频续流在第一次过零时切断。<br>• 氧化锌避雷器：无间隙、非线性特性优异，雷电保护水平由雷电残压与陡波残压/1.15中较大者决定。
6.2 架空输电线路的防雷保护去练习 →• 大气过电压分直击雷与感应雷；直击雷危害最大，感应雷只对35 kV以下线路有威胁。<br>• 防雷性能由耐雷水平（雷击不闪络的最大雷电流幅值，kA）和雷击跳闸率（每100 km·年雷击跳闸次数）衡量。<br>• 感应雷过电压：静电分量为主，极性与雷电流相反，三相同时出现只引起对地闪络；接地避雷线通过耦合系数k降低导线上的感应过电压。<br>• 直击雷三种情况：雷击杆塔塔顶、雷击避雷线档距中央、绕击（雷绕过避雷线击于导线）。<br>• 反击：塔顶电位高于导线电位导致绝缘子串闪络；绕击概率小但一旦发生必引起闪络，保护角越小绕击率越低。<br>• 防雷措施：架设避雷线（分流、耦合、减小感应过电压）、降低杆塔接地电阻、架设耦合地线、双回路不平衡绝缘、自动重合闸、消弧线圈接地、管型避雷器、加强绝缘。
6.3 变电所的防雷保护去练习 →• 直击雷防护：独立避雷针（需校验不反击的空气间隙与土壤间隙）、构架避雷针（适用于110 kV以上配电装置）。<br>• 雷电入侵波防护三大措施：装设阀型避雷器限制幅值；设置进线段保护限制雷电流与波陡度；直配电机母线装电容器限制陡度。<br>• 避雷器紧靠变压器时，变压器电压等于避雷器电压；只要变压器冲击耐压大于避雷器冲击放电电压或最大残压即可受保护。<br>• 电气距离越大，避雷器保护效果越差；110~220 kV变电站流经避雷器电流一般不超过5 kA，取相应残压值。<br>• 进线段保护降低入侵波陡度；35 kV以下变电站避雷器距变压器一般在10 m以内，进线段可缩短为500~600 m。<br>• 三绕组变压器低压绕组开路时也需装避雷器；自耦变压器在中压/高压断路器侧及低压非自耦绕组装避雷器；中性点不接地运行时中性点加装避雷器。
6.4 旋转电机的防雷保护去练习 →• 直配电机：直接与架空线相连的发电机、大型电动机，雷电波可直接传入，防雷要求高于变压器。<br>• 旋转电机出厂耐压值仅为变压器的一半左右，只能与磁吹避雷器FCD在3 kA以下的残压配合。<br>• 措施：发电机母线装FCD避雷器限制幅值（残压略低于电机出厂冲击耐压）；母线上装并联电容器限制陡度保护匝间与中性点绝缘；电缆进线段限制雷电流幅值；必要时加装电抗器。

7. 内部过电压

工频过电压与四类操作过电压的机理、危害和限制措施是本章核心，简答题常按“机理—措施”成对考查。

知识点核心要点
7.1 工频过电压去练习 →• 工频过电压：幅值超过最大工作相电压、频率为工频或接近工频的电压升高；持续时间短则无危险，超高压远距离输电确定绝缘水平时作用重要。<br>• 影响：直接影响操作过电压幅值（常叠加）、影响保护电器工作条件、持续时间长影响绝缘与运行性能。<br>• 限值：线路侧不大于最高运行相电压的1.4倍，母线不大于1.3倍。<br>• 空载长线电容效应：沿线电压呈余弦分布，末端最高；限制措施是装设并联电抗器补偿电容电流。<br>• 不对称接地：单相接地时非故障相电压升高最严重，是确定阀型避雷器额定电压的依据；中性点不接地时非故障相接近线电压。<br>• 甩负荷：甩负荷功率越大，工频电压越高。
7.2.1 间歇电弧接地过电压去练习 →• 中性点不接地系统单相接地电弧时燃时灭，系统状态不断变化，L-C电磁振荡形成遍及全系统的过电压，主要表现为非故障相对地过电压。<br>• 限制措施：中性点直接接地；中性点经消弧线圈接地（减小接地电流）。
7.2.2 空载变压器分闸过电压去练习 →• 原因：流过电感的电流在到达自然零值前被断路器强行切断（截流），电感中磁场能量转化为电容电场能量，导致电压升高。<br>• 断路器断开后L-C振荡，变压器对地电容与连线电容上的电压升高。<br>• 限制措施：在变压器紧靠断路器侧装设避雷器限制过电压。
7.2.3 空载线路分闸过电压去练习 →• 原因：开断空载线路、电容器组等电容性元件时断路器发生重燃，电容元件通过电磁振荡从电源断续获得能量并积累，形成过电压。<br>• 是确定220 kV及以下电气设备操作冲击绝缘水平的主要计算依据。<br>• 限制措施：提高断路器灭弧能力与恢复强度；触头间装并联电阻；线路侧接电磁式电压互感器；线路侧接并联电抗器（降低恢复电压）。
7.2.4 空载线路的合闸过电压去练习 →• 分计划性合闸与自动重合闸两种；计划合闸前线路一般无残余电荷，合闸瞬间电源经电感对线路电容充电发生高频振荡。<br>• 自动重合闸时线路保留残余电荷，非故障相重合后电源对地电容充电，是架空线路最严重的过电压情况。<br>• 限制措施：装并联电抗器降低工频稳态电压；消除和削弱线路残余电压；采用带合闸电阻的断路器；同步合闸；性能良好的避雷器。

8. 绝缘配合

绝缘配合的概念、原则、设备与线路绝缘水平的确定，属于了解性内容，但概念题和多选题易考。

知识点核心要点
8.1 绝缘配合概念及原则去练习 →• 绝缘配合：综合考虑工作电压与各种过电压、保护装置特性、绝缘耐压特性，合理确定必要绝缘水平，使造价、维护费与事故损失综合效益最高。<br>• 绝缘水平：设备绝缘能耐受的试验电压值；同一绝缘对不同作用电压有不同耐受电压。<br>• 决定因素：中性点运行方式（有效接地时绝缘水平较低）、作用电压（最大工作电压/雷电/操作中取最严重者）、保护装置特性、绝缘介质特性等。<br>• 相关试验电压：短时工频（1 min）、干/湿工频放电电压、长时间工频（1~2 h）、雷电冲击、操作冲击。<br>• 220 kV及以下绝缘水平由雷电过电压决定；超高压系统中操作过电压逐渐起控制作用，我国以避雷器保护性能为基础。<br>• 原则：全伏秒特性配合（避雷器伏秒特性在被保护设备下方）；兼顾经济效益；线路绝缘水平一般高于变电站；各电压作用下等效安全系数大致相同。
8.2 电气设备绝缘水平的确定去练习 →• 额定短时工频耐受电压（1 min工频试验电压）；BIL = 额定雷电冲击耐受电压；SIL = 额定操作冲击耐受电压（250/2500 μs）。<br>• 范围I（3.5 kV≤Um≤252 kV）：避雷器只限制雷电过电压，操作过电压由绝缘自身承受；短时工频耐受电压代表综合耐受水平。<br>• BIL按避雷器残压×雷电冲击配合系数KI确定：IEC规定KI≥1.2，我国近距取1.25、远距取1.4；冲击系数βI取1.48。<br>• SIL按系统最高相电压×操作过电压倍数×操作冲击配合系数KS确定，KS=1.15~1.25。
8.3 架空线路绝缘水平的确定去练习 →• 线路绝缘由绝缘子串片数与导线对杆塔（构架）的空气间隙决定。<br>• 绝缘子片数步骤：按机械负荷与环境选型号 → 按工作电压所需爬电比距初定片数 → 按操作过电压与耐雷水平验算调整 → 考虑零值绝缘子修正。<br>• 爬电比距 = 绝缘子总爬电距离 / 系统最高工作电压（有效值）；普通XP-70/XP-160绝缘子有效系数Ke=1。<br>• 操作过电压验算要求湿闪电压大于可能出现的操作过电压并留约10%裕度；污闪与湿闪性能决定外绝缘水平。
