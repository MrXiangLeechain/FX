## 2.2 单相整流

- **单相半波电阻负载输出电压**
  - 可读写法：`Ud = 0.45·U2·(1+cosα)/2`
  - LaTeX：`$$ U_d = 0.45\,U_2\,\frac{1+\cos\alpha}{2} $$`
- **单相桥式电阻负载输出电压**
  - 可读写法：`Ud = 0.45·U2·(1+cosα)   (α=0 时 0.9U2)`
  - LaTeX：`$$ U_d = 0.45\,U_2\,(1+\cos\alpha) $$`
- **单相桥式电感负载输出电压**
  - 可读写法：`Ud = 0.9·U2·cosα   (移相 0~90°)`
  - LaTeX：`$$ U_d = 0.9\,U_2\cos\alpha $$`
- **半波电阻负载输出电流有效值**
  - 可读写法：`I = U2·√[(π−α)/2π + sin2α/4π] ÷ R`
  - LaTeX：`$$ I = \frac{U_2}{R}\sqrt{\frac{\pi-\alpha}{2\pi}+\frac{\sin 2\alpha}{4\pi}} $$`
- **整流功率因数**
  - 可读写法：`PF = P/S = UI/(U2·I)`
  - LaTeX：`$$ PF = \frac{UI}{U_2 I} $$`
- **晶闸管额定电流选型**
  - 可读写法：`IT(AV) = (1.5~2)·IT/1.57`
  - LaTeX：`$$ I_{T(AV)} = \frac{(1.5\sim2)\,I_T}{1.57} $$`
- **晶闸管额定电压选型**
  - 可读写法：`UN = (2~3)·√2·U2`
  - LaTeX：`$$ U_N = (2\sim3)\sqrt{2}\,U_2 $$`

## 2.3 三相整流

- **三相半波电感负载输出电压**
  - 可读写法：`Ud = 1.17·U2·cosα   (移相 0~90°)`
  - LaTeX：`$$ U_d = 1.17\,U_2\cos\alpha $$`
- **三相桥式电感负载输出电压**
  - 可读写法：`Ud = 2.34·U2·cosα = 1.35·UL·cosα`
  - LaTeX：`$$ U_d = 2.34\,U_2\cos\alpha = 1.35\,U_L\cos\alpha $$`
- **三相桥式晶闸管电流有效值**
  - 可读写法：`IT = Id/√3 ≈ 0.577·Id`
  - LaTeX：`$$ I_T = \frac{I_d}{\sqrt{3}} $$`
- **三相桥式变压器二次电流有效值**
  - 可读写法：`I2 = √2·Id/√3 ≈ 0.816·Id`
  - LaTeX：`$$ I_2 = \frac{\sqrt{2}\,I_d}{\sqrt{3}} \approx 0.816\,I_d $$`
- **晶闸管承受最大正反向电压**
  - 可读写法：`单相：√2·U2（相电压峰值）；三相桥：√6·U2（线电压峰值）`
  - LaTeX：`$$ U_m = \sqrt{6}\,U_2\ \text{(三相桥)} $$`

## 2.5 漏抗影响

- **换相重叠角**
  - 可读写法：`cosα − cos(α+γ) = 2·XB·Id/(√6·U2)   (三相)`
  - LaTeX：`$$ \cos\alpha - \cos(\alpha+\gamma) = \frac{2 X_B I_d}{\sqrt{6}\,U_2} $$`
- **换相压降**
  - 可读写法：`ΔUd = m·XB·Id/π   (m=2 单相双半波；三相 m=3)`
  - LaTeX：`$$ \Delta U_d = \frac{m X_B I_d}{\pi} $$`

## 2.6 有源逆变

- **最小逆变角**
  - 可读写法：`βmin = γ + δ(4°~5°) + θ′(≈10°) ≈ 30°~35°`
  - LaTeX：`$$ \beta_{\min} = \gamma + \delta + \theta' \approx 30^{\circ}\!\sim\!35^{\circ} $$`
- **逆变角与触发角关系**
  - 可读写法：`β = 180° − α   (α>90° 逆变)`
  - LaTeX：`$$ \beta = 180^{\circ} - \alpha $$`

## 3.2 交流调压

- **交流调压器电阻负载输出电压有效值**
  - 可读写法：`U = U2·√[(π−α)/π + sin2α/(2π)]`
  - LaTeX：`$$ U = U_2\sqrt{\frac{\pi-\alpha}{\pi}+\frac{\sin 2\alpha}{2\pi}} $$`
- **负载阻抗角**
  - 可读写法：`φ = arctan(ωL/R)`
  - LaTeX：`$$ \varphi = \arctan\frac{\omega L}{R} $$`
- **调压器导通角关系**
  - 可读写法：`θ = f(α, φ)；α<φ 全导通不可调，最小触发角为 φ`
  - LaTeX：`$$ \theta = f(\alpha,\varphi),\quad \alpha_{\min}=\varphi $$`

## 4.2 斩波控制

- **占空比与输出电压**
  - 可读写法：`Uo = (ton/Ts)·Ud = D·Ud`
  - LaTeX：`$$ U_o = \frac{t_{on}}{T_s}U_d = D\,U_d $$`

## 4.3 降压变换器

- **Buck 输出电压 (CCM)**
  - 可读写法：`Uo = D·Ud`
  - LaTeX：`$$ U_o = D\,U_d $$`
- **Buck 电感电流纹波**
  - 可读写法：`ΔiL = (Ud−Uo)·ton/L = Uo(1−D)·Ts/L`
  - LaTeX：`$$ \Delta i_L = \frac{U_o(1-D)T_s}{L} $$`
- **Buck 临界负载电流**
  - 可读写法：`Iok = (1−D)·D·Ud·Ts/(2L)`
  - LaTeX：`$$ I_{ok} = \frac{(1-D)\,D\,U_d T_s}{2L} $$`
- **Buck 输出电压纹波**
  - 可读写法：`ΔUo = ΔiL·Ts/(8C)`
  - LaTeX：`$$ \Delta U_o = \frac{\Delta i_L T_s}{8C} $$`

## 4.4 升压变换器

- **Boost 输出电压 (CCM)**
  - 可读写法：`Uo = Ud/(1−D)`
  - LaTeX：`$$ U_o = \frac{U_d}{1-D} $$`
- **Boost 电感电流纹波**
  - 可读写法：`ΔiL = Ud·D·Ts/L`
  - LaTeX：`$$ \Delta i_L = \frac{U_d D T_s}{L} $$`

## 4.5 升降压变换器

- **Buck-Boost 输出电压 (CCM)**
  - 可读写法：`Uo = D·Ud/(1−D)   (D<0.5 降压，D>0.5 升压，极性相反)`
  - LaTeX：`$$ U_o = \frac{D\,U_d}{1-D} $$`

## 4.7 全桥斩波器

- **双极性控制输出电压**
  - 可读写法：`Uo = (2D−1)·Ud`
  - LaTeX：`$$ U_o = (2D-1)\,U_d $$`

## 5.3 电压型逆变器

- **全桥 180° 导电型基波有效值**
  - 可读写法：`Uo1 = 4·Ud/(π·√2) ≈ 0.9·Ud`
  - LaTeX：`$$ U_{o1} = \frac{4U_d}{\pi\sqrt{2}} $$`

## 5.5 SPWM

- **调制度与载波比**
  - 可读写法：`M = Ur/Uc (0<M<1)；N = fc/fr`
  - LaTeX：`$$ M = \frac{U_r}{U_c},\quad N = \frac{f_c}{f_r} $$`
- **SPWM 基波电压幅值**
  - 可读写法：`Uo1 ≈ M·Ud/2·√2（线性区）`
  - LaTeX：`$$ U_{o1} \approx \frac{M U_d}{2}\cdot\sqrt2 $$`

## 6.3 准谐振

- **谐振角频率与特征阻抗**
  - 可读写法：`ωr = 1/√(Lr·Cr)；Zr = √(Lr/Cr)`
  - LaTeX：`$$ \omega_r = \frac{1}{\sqrt{L_r C_r}},\quad Z_r = \sqrt{\frac{L_r}{C_r}} $$`

## 7.2 保护

- **RC 阻容保护电容**
  - 可读写法：`C ≥ (6·i0%/100)·S/U2²`
  - LaTeX：`$$ C \ge \frac{6\,i_0\%}{100}\cdot\frac{S}{U_2^2} $$`
- **RC 阻容保护电阻（功率）**
  - 可读写法：`Pr ≥ (2·uk%/100)·S   （uk% 为短路电压百分值 5~10）`
  - LaTeX：`$$ P_R \ge \frac{2\,u_k\%}{100}\cdot S $$`

## 7.3 谐波无功

- **谐波畸变率**
  - 可读写法：`THD = √(ΣUh²)/U1 × 100%`
  - LaTeX：`$$ THD = \frac{\sqrt{\sum U_h^2}}{U_1}\times100\% $$`
