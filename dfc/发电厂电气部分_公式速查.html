2.1 发热与电动力两平行导体电动力
F = 2×10^-7 · i1·i2 · (L/a) (N)
F = 2\times10^{-7}\, i_1 i_2 \frac{L}{a}
2.1 发热与电动力三相短路最大电动力（中间相）
F(max) ≈ √3 × 10^-7 · ish² · (L/a)
F_{\max} \approx \sqrt{3}\times10^{-7}\, i_{sh}^2 \frac{L}{a}
2.1 发热与电动力长期发热温升
τ = τ∞(1 − e^(−t/T))
\tau = \tau_\infty (1-e^{-t/T})
2.1 发热与电动力长期发热校验
Ial ≥ Imax
I_{al} \ge I_{\max}
2.1 发热与电动力短时发热热效应
Qt = ∫ ik² dt ≤ It²·t
Q_k = \int i_k^2\,dt \le I_t^2\, t
2.1 发热与电动力母线机械强度校验
σjs ≤ σal（硬铝约 70 MPa）
\sigma_{js} \le \sigma_{al}
3.1 电弧与灭弧交流电弧最终熄灭条件
ud(t) ≥ ur(t)
u_d(t) \ge u_r(t)
3.1 电弧与灭弧双断口电压分配（不均压）
U1 ≈ (2/3)U，U2 ≈ (1/3)U
U_1 \approx \tfrac{2}{3}U,\quad U_2 \approx \tfrac{1}{3}U
3.1 电弧与灭弧双断口电压分配（装均压电容后）
U1 ≈ U2 ≈ U/2
U_1 \approx U_2 \approx \frac{U}{2}
3.1 电弧与灭弧全开断时间
tbr = 固有分闸时间 tin + 燃弧时间 ta
t_{br} = t_{in} + t_a
3.1 电弧与灭弧断路器速度等级
tbr < 0.08s 快速；0.08~0.12s 中速；> 0.12s 低速
t_{br}<0.08\,s\ \text{快速}
4.3 主变压器选择单元接线主变容量
ST = 1.1·PG·(1 − kp) / cosΦ
S_T = 1.1\,P_G (1-k_p)/\cos\Phi
4.3 主变压器选择发电机电压母线主变容量（剩余功率送出）
S ≈ Σ[SGi(1−kp)]/cosφ − Smin
S \approx \sum_i \frac{S_{Gi}(1-k_p)}{\cos\varphi} - S_{\min}
4.3 主变压器选择发电机电压母线主变容量（最大机倒送）
S ≈ Smax − Σ[SGi(1−kp)]/cosφ（其余机组）
S \approx S_{\max} - \sum_{i\ne m}\frac{S_{Gi}(1-k_p)}{\cos\varphi}
4.4 限制短路电流出线电抗器电压损失
ΔU% = (Imax/IN)·XL%·sinφ ≤ 5%
\Delta U\% = \frac{I_{\max}}{I_N} X_L\% \sin\varphi \le 5\%
4.4 限制短路电流母线残压校验
ΔUre% = (I″/IN)·XL% ≥ 60%~70%
\Delta U_{re}\% = \frac{I''}{I_N} X_L\% \ge (60\sim70)\%
4.4 限制短路电流所需电抗标幺值
x*L = x*Σ − x*Σ′（x*Σ = Id/I″）
x^{*}_{L} = x^{*}_{\Sigma} - x^{*\prime}_{\Sigma}
4.4 限制短路电流电抗器百分电抗换算
XL(%) = x*L · (IN/Id) × 100%
X_L\% = x^{*}_{L}\cdot\frac{I_N}{I_d}\times100\%
4.4 限制短路电流出线电抗器百分电抗取值
XK% = 3%~6%
X_K\% = (3\sim6)\%
5.2 厂用负荷计算换算系数法
S = Σ (K·P) / (η·cosφ)
S = \sum \frac{K P}{\eta\cos\varphi}
5.2 厂用负荷计算轴功率法
S = Km·Pmax/(η·cosφ) + ΣSL（Km 新建 0.9、扩建 0.95）
S = \frac{K_m P_{\max}}{\eta\cos\varphi} + \Sigma S_L
5.2 厂用负荷计算修配厂负荷折算
P = 0.14·ΣP + 0.4·ΣP5
P = 0.14\Sigma P + 0.4\Sigma P_5

6.3 电抗器选择百分电抗定义
XL% = XK/XN × 100%，XN = UN/(√3·IN)
X_L\% = \frac{X_K}{X_N}\times100\%,\ X_N=\frac{U_N}{\sqrt3 I_N}

x^{*}_{\Sigma} = \frac{I_d}{I''},\quad x^{*}_{L}=x^{*}_{\Sigma}-x^{*\prime}_{\Sigma}
