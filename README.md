每门课 4 个文件：知识点总结与复习计划、练习题库、公式速查 HTML、公式速查 Markdown 源文件。

## 使用

- 从 `index.html` 进入，页面之间互相跳转。
- 练习题库支持按章节/题型筛选，错题自动记入浏览器 localStorage（换浏览器/设备不共享）。
- 总结页每个知识点可深链到对应练习（`练习题库.html?part=章节&num=编号&autostart=1`）。
- 公式页可一键复制 LaTeX。

## 部署 GitHub Pages

整个目录上传到仓库后，在 Settings → Pages 选择分支即可，无需构建。
