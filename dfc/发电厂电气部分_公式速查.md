## 2.1 发热与电动力

- **两平行导体电动力**
  - 可读写法：`F = 2×10^-7 · i1·i2 · (L/a)   (N)`
  - LaTeX：`$$ F = 2\times10^{-7}\, i_1 i_2 \frac{L}{a} $$`
- **三相短路最大电动力（中间相）**
  - 可读写法：`F(max) ≈ √3 × 10^-7 · ish² · (L/a)`
  - LaTeX：`$$ F_{\max} \approx \sqrt{3}\times10^{-7}\, i_{sh}^2 \frac{L}{a} $$`
- **长期发热温升**
  - 可读写法：`τ = τ∞(1 − e^(−t/T))`
  - LaTeX：`$$ \tau = \tau_\infty (1-e^{-t/T}) $$`
- **长期发热校验**
  - 可读写法：`Ial ≥ Imax`
  - LaTeX：`$$ I_{al} \ge I_{\max} $$`
- **短时发热热效应**
  - 可读写法：`Qt = ∫ ik² dt  ≤ It²·t`
  - LaTeX：`$$ Q_k = \int i_k^2\,dt \le I_t^2\, t $$`
- **母线机械强度校验**
  - 可读写法：`σjs ≤ σal（硬铝约 70 MPa）`
  - LaTeX：`$$ \sigma_{js} \le \sigma_{al} $$`

## 3.1 电弧与灭弧

- **交流电弧最终熄灭条件**
  - 可读写法：`ud(t) ≥ ur(t)`
  - LaTeX：`$$ u_d(t) \ge u_r(t) $$`
- **双断口电压分配（不均压）**
  - 可读写法：`U1 ≈ (2/3)U，U2 ≈ (1/3)U`
  - LaTeX：`$$ U_1 \approx \tfrac{2}{3}U,\quad U_2 \approx \tfrac{1}{3}U $$`
- **双断口电压分配（装均压电容后）**
  - 可读写法：`U1 ≈ U2 ≈ U/2`
  - LaTeX：`$$ U_1 \approx U_2 \approx \frac{U}{2} $$`
- **全开断时间**
  - 可读写法：`tbr = 固有分闸时间 tin + 燃弧时间 ta`
  - LaTeX：`$$ t_{br} = t_{in} + t_a $$`
- **断路器速度等级**
  - 可读写法：`tbr < 0.08s 快速；0.08~0.12s 中速；> 0.12s 低速`
  - LaTeX：`$$ t_{br}<0.08\,s\ \text{快速} $$`

## 4.3 主变压器选择

- **单元接线主变容量**
  - 可读写法：`ST = 1.1·PG·(1 − kp) / cosΦ`
  - LaTeX：`$$ S_T = 1.1\,P_G (1-k_p)/\cos\Phi $$`
- **发电机电压母线主变容量（剩余功率送出）**
  - 可读写法：`S ≈ Σ[SGi(1−kp)]/cosφ − Smin`
  - LaTeX：`$$ S \approx \sum_i \frac{S_{Gi}(1-k_p)}{\cos\varphi} - S_{\min} $$`
- **发电机电压母线主变容量（最大机倒送）**
  - 可读写法：`S ≈ Smax − Σ[SGi(1−kp)]/cosφ（其余机组）`
  - LaTeX：`$$ S \approx S_{\max} - \sum_{i\ne m}\frac{S_{Gi}(1-k_p)}{\cos\varphi} $$`

## 4.4 限制短路电流

- **出线电抗器电压损失**
  - 可读写法：`ΔU% = (Imax/IN)·XL%·sinφ ≤ 5%`
  - LaTeX：`$$ \Delta U\% = \frac{I_{\max}}{I_N} X_L\% \sin\varphi \le 5\% $$`
- **母线残压校验**
  - 可读写法：`ΔUre% = (I″/IN)·XL% ≥ 60%~70%`
  - LaTeX：`$$ \Delta U_{re}\% = \frac{I''}{I_N} X_L\% \ge (60\sim70)\% $$`
- **所需电抗标幺值**
  - 可读写法：`x*L = x*Σ − x*Σ′（x*Σ = Id/I″）`
  - LaTeX：`$$ x^{*}_{L} = x^{*}_{\Sigma} - x^{*\prime}_{\Sigma} $$`
- **电抗器百分电抗换算**
  - 可读写法：`XL(%) = x*L · (IN/Id) × 100%`
  - LaTeX：`$$ X_L\% = x^{*}_{L}\cdot\frac{I_N}{I_d}\times100\% $$`
- **出线电抗器百分电抗取值**
  - 可读写法：`XK% = 3%~6%`
  - LaTeX：`$$ X_K\% = (3\sim6)\% $$`

## 5.2 厂用负荷计算

- **换算系数法**
  - 可读写法：`S = Σ (K·P) / (η·cosφ)`
  - LaTeX：`$$ S = \sum \frac{K P}{\eta\cos\varphi} $$`
- **轴功率法**
  - 可读写法：`S = Km·Pmax/(η·cosφ) + ΣSL（Km 新建 0.9、扩建 0.95）`
  - LaTeX：`$$ S = \frac{K_m P_{\max}}{\eta\cos\varphi} + \Sigma S_L $$`
- **修配厂负荷折算**
  - 可读写法：`P = 0.14·ΣP + 0.4·ΣP5`
  - LaTeX：`$$ P = 0.14\Sigma P + 0.4\Sigma P_5 $$`

## 6.1 设备选择

- **额定电压选择**
  - 可读写法：`Ualm ≥ USN（Ualm ≈ 1.1~1.15 UN）`
  - LaTeX：`$$ U_{alm} \ge U_{SN} $$`
- **额定电流选择**
  - 可读写法：`IN ≥ Imax`
  - LaTeX：`$$ I_N \ge I_{\max} $$`
- **发电机回路最大持续工作电流**
  - 可读写法：`Imax = 1.05·IGN`
  - LaTeX：`$$ I_{\max} = 1.05\,I_{GN} $$`
- **海拔修正**
  - 可读写法：`每增加 100 m，最高工作电压降低 1%`
  - LaTeX：`$$ \Delta U = 1\%\,/\,100\,m $$`
- **热稳定校验**
  - 可读写法：`Qt ≤ It²·t`
  - LaTeX：`$$ Q_k \le I_t^2\, t $$`
- **动稳定校验**
  - 可读写法：`ies ≥ ish  或  Ies ≥ Ish`
  - LaTeX：`$$ i_{es} \ge i_{sh}\ \text{或}\ I_{es} \ge I_{sh} $$`
- **开断计算时间**
  - 可读写法：`tk′ = tpr1 + tin（主保护动作时间+固有分闸时间）`
  - LaTeX：`$$ t_k' = t_{pr1} + t_{in} $$`
- **热效应计算时间**
  - 可读写法：`tk = tpr + tbr（后备保护+全开断时间）`
  - LaTeX：`$$ t_k = t_{pr} + t_{br} $$`

## 6.2 互感器

- **TA 额定电流比**
  - 可读写法：`kI = I1N/I2N = N2/N1`
  - LaTeX：`$$ k_I = \frac{I_{1N}}{I_{2N}} = \frac{N_2}{N_1} $$`
- **TA 电流误差**
  - 可读写法：`fi = (kI·I2 − I1)/I1 × 100%`
  - LaTeX：`$$ f_i = \frac{k_I I_2 - I_1}{I_1}\times100\% $$`
- **TA 额定容量**
  - 可读写法：`S2N = I2N² · Z2N`
  - LaTeX：`$$ S_{2N} = I_{2N}^2 Z_{2N} $$`
- **TA 准确级保证条件**
  - 可读写法：`Z2L ≤ Z2N`
  - LaTeX：`$$ Z_{2L} \le Z_{2N} $$`
- **TA 二次负载组成**
  - 可读写法：`Z2 = Σra + rc + rre（仪表/继电器电阻+电缆+接触电阻）`
  - LaTeX：`$$ Z_2 = \Sigma r_a + r_c + r_{re} $$`

## 6.3 电抗器选择

- **百分电抗定义**
  - 可读写法：`XL% = XK/XN × 100%，XN = UN/(√3·IN)`
  - LaTeX：`$$ X_L\% = \frac{X_K}{X_N}\times100\%,\ X_N=\frac{U_N}{\sqrt3 I_N} $$`
- **限流要求所需电抗**
  - 可读写法：`x*Σ = Id/I″，x*L = x*Σ − x*Σ′`
  - LaTeX：`$$ x^{*}_{\Sigma} = \frac{I_d}{I''},\quad x^{*}_{L}=x^{*}_{\Sigma}-x^{*\prime}_{\Sigma} $$`
- **电压损失校验**
  - 可读写法：`ΔU% = (Imax/IN)·XL%·sinφ ≤ 5%`
  - LaTeX：`$$ \Delta U\% = \frac{I_{\max}}{I_N} X_L\% \sin\varphi \le 5\% $$`
- **母线残压校验**
  - 可读写法：`ΔUre% = (I″/IN)·XL% ≥ 60%~70%`
  - LaTeX：`$$ \Delta U_{re}\% = \frac{I''}{I_N} X_L\% \ge (60\sim70)\% $$`

## 7.1 安全净距

- **B1 带电部分至栅状遮栏**
  - 可读写法：`B1 = A1 + 750 mm`
  - LaTeX：`$$ B_1 = A_1 + 750\,\mathrm{mm} $$`
- **B2 带电部分至网状遮栏**
  - 可读写法：`B2 = A1 + 70 + 30 mm`
  - LaTeX：`$$ B_2 = A_1 + 70 + 30\,\mathrm{mm} $$`
- **B3 带电部分至板状遮栏**
  - 可读写法：`B3 = A1 + 30 mm`
  - LaTeX：`$$ B_3 = A_1 + 30\,\mathrm{mm} $$`
- **C 值（无遮栏裸导体至地面）**
  - 可读写法：`屋外 C = A1 + 2300 + 200 mm；屋内 C = A1 + 2300 mm`
  - LaTeX：`$$ C_{\text{屋外}} = A_1 + 2300 + 200\,\mathrm{mm} $$`
- **D 值（平行无遮栏裸导体间）**
  - 可读写法：`屋外 D = A1 + 1800 + 200 mm；屋内 D = A1 + 1800 mm`
  - LaTeX：`$$ D_{\text{屋外}} = A_1 + 1800 + 200\,\mathrm{mm} $$`
- **E 值（出线套管至屋外路面）**
  - 可读写法：`35kV 及以下 E = 4000 mm；≥60kV 取 E = A1 + 3500 mm`
  - LaTeX：`$$ E_{\le35kV} = 4000\,\mathrm{mm} $$`
