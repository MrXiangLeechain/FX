2.2 单相整流单相半波电阻负载输出电压
Ud = 0.45·U2·(1+cosα)/2
U_d = 0.45\,U_2\,\frac{1+\cos\alpha}{2}
2.2 单相整流单相桥式电阻负载输出电压
Ud = 0.45·U2·(1+cosα) (α=0 时 0.9U2)
U_d = 0.45\,U_2\,(1+\cos\alpha)
2.2 单相整流单相桥式电感负载输出电压
Ud = 0.9·U2·cosα (移相 0~90°)
U_d = 0.9\,U_2\cos\alpha
2.2 单相整流半波电阻负载输出电流有效值
I = U2·√[(π−α)/2π + sin2α/4π] ÷ R
I = \frac{U_2}{R}\sqrt{\frac{\pi-\alpha}{2\pi}+\frac{\sin 2\alpha}{4\pi}}
2.2 单相整流整流功率因数
PF = P/S = UI/(U2·I)
PF = \frac{UI}{U_2 I}
2.2 单相整流晶闸管额定电流选型
IT(AV) = (1.5~2)·IT/1.57
I_{T(AV)} = \frac{(1.5\sim2)\,I_T}{1.57}
2.2 单相整流晶闸管额定电压选型
UN = (2~3)·√2·U2
U_N = (2\sim3)\sqrt{2}\,U_2
2.3 三相整流三相半波电感负载输出电压
Ud = 1.17·U2·cosα (移相 0~90°)
U_d = 1.17\,U_2\cos\alpha
2.3 三相整流三相桥式电感负载输出电压
Ud = 2.34·U2·cosα = 1.35·UL·cosα
U_d = 2.34\,U_2\cos\alpha = 1.35\,U_L\cos\alpha
2.3 三相整流三相桥式晶闸管电流有效值
IT = Id/√3 ≈ 0.577·Id
I_T = \frac{I_d}{\sqrt{3}}
2.3 三相整流三相桥式变压器二次电流有效值
I2 = √2·Id/√3 ≈ 0.816·Id
I_2 = \frac{\sqrt{2}\,I_d}{\sqrt{3}} \approx 0.816\,I_d
2.3 三相整流晶闸管承受最大正反向电压
单相：√2·U2（相电压峰值）；三相桥：√6·U2（线电压峰值）
U_m = \sqrt{6}\,U_2\ \text{(三相桥)}
2.5 漏抗影响换相重叠角
cosα − cos(α+γ) = 2·XB·Id/(√6·U2) (三相)
\cos\alpha - \cos(\alpha+\gamma) = \frac{2 X_B I_d}{\sqrt{6}\,U_2}
2.5 漏抗影响换相压降
ΔUd = m·XB·Id/π (m=2 单相双半波；三相 m=3)
\Delta U_d = \frac{m X_B I_d}{\pi}
2.6 有源逆变最小逆变角
βmin = γ + δ(4°~5°) + θ′(≈10°) ≈ 30°~35°
\beta_{\min} = \gamma + \delta + \theta' \approx 30^{\circ}\!\sim\!35^{\circ}
2.6 有源逆变逆变角与触发角关系
β = 180° − α (α>90° 逆变)
\beta = 180^{\circ} - \alpha
3.2 交流调压交流调压器电阻负载输出电压有效值

4.2 斩波控制占空比与输出电压
Uo = (ton/Ts)·Ud = D·Ud
U_o = \frac{t_{on}}{T_s}U_d = D\,U_d
4.3 降压变换器Buck 输出电压 (CCM)
Uo = D·Ud
U_o = D\,U_d
4.3 降压变换器Buck 电感电流纹波
ΔiL = (Ud−Uo)·ton/L = Uo(1−D)·Ts/L
\Delta i_L = \frac{U_o(1-D)T_s}{L}
4.3 降压变换器Buck 临界负载电流
Iok = (1−D)·D·Ud·Ts/(2L)
I_{ok} = \frac{(1-D)\,D\,U_d T_s}{2L}
4.3 降压变换器Buck 输出电压纹波
ΔUo = ΔiL·Ts/(8C)
\Delta U_o = \frac{\Delta i_L T_s}{8C}
4.4 升压变换器Boost 输出电压 (CCM)
Uo = Ud/(1−D)
U_o = \frac{U_d}{1-D}
4.4 升压变换器Boost 电感电流纹波

4.5 升降压变换器Buck-Boost 输出电压 (CCM)

U_{o1} \approx \frac{M U_d}{2}\cdot\sqrt2
6.3 准谐振谐振角频率与特征阻抗
