## 2.2 互感器

- **TA 变比**
  - 可读写法：`KTA = I1N / I2N ≈ W2 / W1`
  - LaTeX：`$$ K_{TA} = \frac{I_{1N}}{I_{2N}} \approx \frac{W_2}{W_1} $$`
- **TA 磁势平衡**
  - 可读写法：`W1·I1 - W2·I2 = W1·Im（正常时 W1I1 与 W2I2 大部分抵消）`
  - LaTeX：`$$ \dot{W_1 I_1} - \dot{W_2 I_2} = W_1 \dot{I_m} $$`
- **TA 电流误差（比差）**
  - 可读写法：`f% = (I2' - I1) / I1 × 100%`
  - LaTeX：`$$ f = \frac{I_2' - I_1}{I_1} \times 100\% $$`
- **TA 角误差**
  - 可读写法：`δ ≈ I'm·sinα（弧度）`
  - LaTeX：`$$ \delta \approx I_m' \sin\alpha \ (\text{rad}) $$`
- **TA 额定容量**
  - 可读写法：`S2N = I2N² · Z2N（二次电流标准化后可用 Z2N 表征）`
  - LaTeX：`$$ S_{2N} = I_{2N}^2 Z_{2N} $$`
- **TV 变比**
  - 可读写法：`KTV = U1N / U2N（相当于空载运行的小容量降压变压器）`
  - LaTeX：`$$ K_{TV} = \frac{U_{1N}}{U_{2N}} $$`
- **TV 电压误差**
  - 可读写法：`ΔU% = (KU·U2 - U1) / U1 × 100%`
  - LaTeX：`$$ \Delta U = \frac{K_U U_2 - U_1}{U_1} \times 100\% $$`
- **电容式 TV 分压**
  - 可读写法：`U2 = U1 · C1 / (C1 + C2)，K = C1/(C1+C2)`
  - LaTeX：`$$ U_2 = U_1 \frac{C_1}{C_1 + C_2} $$`
- **变换器 UA 输出**
  - 可读写法：`U2 = İ2·R = KI·I1，KI = KTA·R（输出与输入电流成正比且同相位）`
  - LaTeX：`$$ \dot{U_2} = \dot{I_2} R = K_I \dot{I_1} $$`
- **电抗变换器 UX**
  - 可读写法：`U2 = jXUX·I1（转移阻抗，气隙大磁路不饱和时为常数）`
  - LaTeX：`$$ \dot{U_2} = j X_{UX} \dot{I_1} $$`
- **零序电流滤过器**
  - 可读写法：`Ir = (İa+İb+İc) = (3I0)/KTA - Iunb`
  - LaTeX：`$$ \dot{I_r} = \frac{3 \dot{I_0}}{K_{TA}} - \dot{I_{unb}} $$`

## 3.1 电流保护

- **短路电流通用式**
  - 可读写法：`Ik = E·KΦ / (Zs + Zk)，三相短路 KΦ=1，两相 KΦ=√3/2`
  - LaTeX：`$$ I_k = \frac{E \cdot K_\Phi}{Z_s + Z_k},\ K_\Phi^{(3)}=1,\ K_\Phi^{(2)}=\tfrac{\sqrt{3}}{2} $$`
- **电流Ⅰ段整定**
  - 可读写法：`Iset' = Krel' · Ik.B.max，Krel' = 1.2～1.3`
  - LaTeX：`$$ I_{set}^{I} = K_{rel}^{I} \, I_{k.B.max} $$`
- **电流Ⅰ段最小保护范围**
  - 可读写法：`lmin/l = (E/Iset' - Zs.max)/(z1·lAB) × 100%，要求 ≥15%～20%`
  - LaTeX：`$$ \frac{l_{min}}{l} = \frac{E/I_{set}^{I} - Z_{s.max}}{z_1 l_{AB}} \times 100\% \ge 15\% $$`
- **电流Ⅱ段整定**
  - 可读写法：`Iset'' = Krel'' · Iset1'，Krel'' = 1.1～1.2；t'' = t' + Δt，Δt = 0.5s`
  - LaTeX：`$$ I_{set}^{II} = K_{rel}^{II} \, I_{set1}^{I} $$`
- **电流Ⅱ段灵敏度**
  - 可读写法：`Ksen'' = Ik.B.min / Iset'' ≥ 1.3～1.5`
  - LaTeX：`$$ K_{sen}^{II} = \frac{I_{k.B.min}}{I_{set}^{II}} \ge 1.3 \sim 1.5 $$`
- **电流Ⅲ段整定**
  - 可读写法：`Iset''' = Krel''' · Kss / Kre · IL.max（Kss 自启动系数，Kre 返回系数）`
  - LaTeX：`$$ I_{set}^{III} = \frac{K_{rel}^{III} K_{ss}}{K_{re}} I_{L.max} $$`
- **电流Ⅲ段时限**
  - 可读写法：`t'''n = t'''(n+1) + Δt（阶梯原则）`
  - LaTeX：`$$ t_n^{III} = t_{n+1}^{III} + \Delta t $$`
- **返回系数**
  - 可读写法：`Kre = Ire / Iop（过量继电器 Kre < 1，一般 0.85～0.9）`
  - LaTeX：`$$ K_{re} = \frac{I_{re}}{I_{op}} < 1 $$`
- **反时限特性（标准）**
  - 可读写法：`t = 0.14·tOP / ((I/Ip)^0.02 - 1)`
  - LaTeX：`$$ t = \frac{0.14\, t_{OP}}{(I/I_p)^{0.02} - 1} $$`

## 3.2 方向保护

- **方向元件幅值比较**
  - 可读写法：`|U̇m + KU̇m'| > |U̇m - KU̇m'|，KU̇m' = İm·ZK`
  - LaTeX：`$$ |\dot{U_m} + K\dot{U_m}'| > |\dot{U_m} - K\dot{U_m}'| $$`
- **方向元件相位比较**
  - 可读写法：`-90° ≤ arg(U̇m / KU̇m') ≤ 90°`
  - LaTeX：`$$ -90^\circ \le \arg\frac{\dot{U_m}}{K\dot{U_m}'} \le 90^\circ $$`
- **最大灵敏角（90°接线）**
  - 可读写法：`φsen = -30°（电压超前电流），由各故障类型角度范围角平分线确定`
  - LaTeX：`$$ \varphi_{sen} = -30^\circ $$`

## 3.3 零序保护

- **单相接地零序电流**
  - 可读写法：`3I0k(1) = 3E / (Z1Σ + Z2Σ + Z0Σ)，工程取 Z1Σ=Z2Σ`
  - LaTeX：`$$ 3 I_{0k}^{(1)} = \frac{3E}{Z_{1\Sigma} + Z_{2\Sigma} + Z_{0\Sigma}} $$`
- **两相接地零序电流**
  - 可读写法：`3I0k(1,1) = 3E·Z2Σ / [Z1Σ(Z1Σ + Z2Σ + Z0Σ)]`
  - LaTeX：`$$ 3 I_{0k}^{(1,1)} = \frac{3E\, Z_{2\Sigma}}{Z_{1\Sigma}(Z_{1\Sigma}+Z_{2\Sigma}+Z_{0\Sigma})} $$`
- **零序Ⅰ段整定**
  - 可读写法：`I0set' = Krel · 3I0k.max，Krel = 1.2～1.3`
  - LaTeX：`$$ I_{0.set}^{I} = K_{rel}\, 3 I_{0k.max} $$`
- **零序电流分配系数**
  - 可读写法：`C0M = Z0N / (Z0M + Z0N)，IM0 = C0M·IK0，且 C0M + C0N = 1`
  - LaTeX：`$$ C_{0M} = \frac{Z_{0N}}{Z_{0M}+Z_{0N}},\ \dot{I}_{M0} = C_{0M}\dot{I}_{K0} $$`
- **零序分支系数**
  - 可读写法：`Kb = I0m / I0M（保护处电流与短路点电流之比，整定取最小值）`
  - LaTeX：`$$ K_b = \frac{I_{0m}}{I_{0M}} $$`
- **零序Ⅱ段整定**
  - 可读写法：`I0set'' = Krel · Kb.min · I0set(下级Ⅰ段)`
  - LaTeX：`$$ I_{0.set}^{II} = K_{rel}\, K_{b.min}\, I_{0.set}^{I(\text{下级})} $$`
- **零序方向最灵敏**
  - 可读写法：`arg(-3U̇0/3İ0) ≈ 180°-φK0 = 95°～110°，即 3İ0 滞后 3U̇0 约 100°～110°`
  - LaTeX：`$$ 3\dot{I_0}\ \text{滞后}\ 3\dot{U_0}\ 100^\circ \sim 110^\circ $$`

## 3.4 小电流接地

- **单相接地零序电压**
  - 可读写法：`U0 ≈ -E（各处近似相同）`
  - LaTeX：`$$ \dot{U_0} \approx -\dot{E} $$`
- **非故障线路零序电流**
  - 可读写法：`I0(线路) = jω·C0·U0（自身对地电容电流，母线流向线路）`
  - LaTeX：`$$ \dot{I}_{0(\text{非故障})} = j\omega C_0 \dot{U_0} $$`

## 3.5 继电器

- **电磁力矩**
  - 可读写法：`Me = K·I²（与电流平方成正比，与方向无关）`
  - LaTeX：`$$ M_e = K I^2 $$`
- **动作/返回条件**
  - 可读写法：`动作：Me ≥ Ms + Mf；返回：Me ≤ Ms - Mf`
  - LaTeX：`$$ M_e \ge M_s + M_f\ (\text{动作}),\quad M_e \le M_s - M_f\ (\text{返回}) $$`
- **返回系数**
  - 可读写法：`Kre = Ire / Iop（过量 <1，欠量 >1）`
  - LaTeX：`$$ K_{re} = \frac{I_{re}}{I_{op}} $$`

## 4.1 距离保护

- **测量阻抗**
  - 可读写法：`Zm = U̇m / İm = lk · z1（正比于短路距离）`
  - LaTeX：`$$ Z_m = \frac{\dot{U_m}}{\dot{I_m}} = l_k z_1 $$`
- **零序补偿系数**
  - 可读写法：`K0 = (Z0 - Z1) / (3Z1)（单位长度或全长参数）`
  - LaTeX：`$$ K_0 = \frac{Z_0 - Z_1}{3 Z_1} $$`
- **接地距离测量电压**
  - 可读写法：`U̇φ / (İφ + 3K0·İ0) = Z1K（故障相）`
  - LaTeX：`$$ Z_m = \frac{\dot{U_\varphi}}{\dot{I_\varphi} + 3 K_0 \dot{I_0}} = Z_{1K} $$`
- **方向圆幅值比较**
  - 可读写法：`|Żm - ½Żset| ≤ ½|Zset|`
  - LaTeX：`$$ \left| \dot{Z_m} - \tfrac{1}{2}\dot{Z_{set}} \right| \le \tfrac{1}{2} |Z_{set}| $$`
- **全阻抗圆幅值比较**
  - 可读写法：`|Żm| ≤ |Zset|`
  - LaTeX：`$$ |\dot{Z_m}| \le |Z_{set}| $$`
- **圆特性幅值比较（通用）**
  - 可读写法：`|Żm - Ż0| ≤ r（Z0 圆心，r 半径）`
  - LaTeX：`$$ |\dot{Z_m} - \dot{Z_0}| \le r $$`
- **偏移圆幅值比较**
  - 可读写法：`½(1+α)|Zset| ≥ |Żm - (1-α)·½Żset|`
  - LaTeX：`$$ \tfrac{1+\alpha}{2}|Z_{set}| \ge \left| \dot{Z_m} - \tfrac{1-\alpha}{2}\dot{Z_{set}} \right| $$`
- **圆特性相位比较（通用）**
  - 可读写法：`90° ≤ arg[(Żset - Żm) / (Żm + α·Żset)] ≤ 270°`
  - LaTeX：`$$ 90^\circ \le \arg\frac{\dot{Z_{set}}-\dot{Z_m}}{\dot{Z_m}+\alpha\dot{Z_{set}}} \le 270^\circ $$`

## 4.2 距离整定

- **距离Ⅰ段整定**
  - 可读写法：`Zset' = Krel'·ZAB，Krel' = 0.8～0.85`
  - LaTeX：`$$ Z_{set}^{I} = K_{rel}^{I}\, Z_{AB} $$`
- **距离Ⅱ段整定**
  - 可读写法：`Zset'' = Krel''·(ZAB + Kb·Zset3')，Krel'' = 0.8，Kb 取最小分支系数`
  - LaTeX：`$$ Z_{set}^{II} = K_{rel}^{II}(Z_{AB} + K_b Z_{set3}^{I}) $$`
- **距离Ⅲ段躲负荷**
  - 可读写法：`Zop''' = 0.9UN / (Krel'''·Kss·Kre·IL.max)；方向圆换算 Zset''' = Zop'''/cos(φL-φsen)`
  - LaTeX：`$$ Z_{op}^{III} = \frac{0.9 U_N}{K_{rel}^{III} K_{ss} K_{re} I_{L.max}} $$`
- **距离Ⅲ段灵敏度**
  - 可读写法：`近后备 Ksen(1) = Zset'''/ZAB ≥ 1.5；远后备 Ksen(2) = Zset'''/(ZAB+Kb.max·ZBC) ≥ 1.2`
  - LaTeX：`$$ K_{sen}^{(1)} \ge 1.5,\quad K_{sen}^{(2)} \ge 1.2 $$`
- **分支系数**
  - 可读写法：`Kb = İ2/İ3；助增 Kb>1 使 Zm=ZAB+Kb·Zk 增大，外汲 Kb<1 使 Zm 减小`
  - LaTeX：`$$ K_b = \frac{\dot{I}_2}{\dot{I}_3},\quad Z_m = Z_{AB} + K_b Z_k $$`

## 4.2 振荡

- **振荡电流**
  - 可读写法：`İm = (ĚM - ĚN)/ZΣ = 2EM·sin(δ/2)·e^{jφ}/ZΣ`
  - LaTeX：`$$ \dot{I_m} = \frac{2 E_M \sin\frac{\delta}{2}}{Z_\Sigma} $$`
- **振荡中心电压**
  - 可读写法：`Uos = EM·cos(δ/2)（两侧电势相等、阻抗角相同时振荡中心在 ZΣ/2）`
  - LaTeX：`$$ U_{OS} = E_M \cos\tfrac{\delta}{2} $$`
- **振荡时测量阻抗轨迹**
  - 可读写法：`Żm = ŻM - ZΣ·(½ - j·ctg(δ/2)/2)，轨迹为 ZΣ 的垂直平分线`
  - LaTeX：`$$ \dot{Z_m} = \dot{Z_M} - Z_\Sigma\left( \tfrac{1}{2} - j\tfrac{\mathrm{ctg}\frac{\delta}{2}}{2} \right) $$`
- **振荡误动时间**
  - 可读写法：`t = (δ3 - δ2)/δS · 360°/T（误动角区/滑差角速度）`
  - LaTeX：`$$ t = \frac{\delta_3 - \delta_2}{\delta_S}\cdot\frac{360^\circ}{T} $$`

## 4.3 特殊问题

- **电弧电阻**
  - 可读写法：`Rg ≈ 50·l / Ig（l 单位 m，Ig 单位 A；弧光电压约 5%UN 近似恒定）`
  - LaTeX：`$$ R_g \approx \frac{50\, l}{I_g} $$`
- **双侧电源过渡电阻影响**
  - 可读写法：`Żm = Rg·e^{jα}(İk'/İk'') + Zk，α = arg(İk'/İk'')`
  - LaTeX：`$$ \dot{Z_m} = R_g e^{j\alpha} \frac{\dot{I_k}'}{\dot{I_k}''} + Z_k $$`
- **突变量距离补偿电压**
  - 可读写法：`ΔU̇op = ΔU̇m - Δİm·Zset；区内故障判据 |ΔU̇op| ≥ |ΔU̇k|`
  - LaTeX：`$$ \Delta\dot{U}_{op} = \Delta\dot{U}_m - \Delta\dot{I}_m Z_{set},\ |\Delta\dot{U}_{op}| \ge |\Delta\dot{U}_k| $$`
- **突变量距离正向动作特性**
  - 可读写法：`|ZS + Zset| ≥ |ZS + ZK|（正向区内）；反方向 ZR > Zset`
  - LaTeX：`$$ |Z_S + Z_{set}| \ge |Z_S + Z_K| $$`

## 6.1 重合闸

- **重合闸时间（单侧电源）**
  - 可读写法：`tARC = tu（去游离）+ tQF（断路器复原）+ 裕度`
  - LaTeX：`$$ t_{ARC} = t_u + t_{QF} + \text{裕度} $$`
- **重合闸时间（双侧电源）**
  - 可读写法：`tARC = (t2.QF + t2.p - t1.p - t1.QF) + tu + 裕度（按最不利：对侧延时跳闸）`
  - LaTeX：`$$ t_{ARC} = (t_{2.QF}+t_{2.p}-t_{1.p}-t_{1.QF}) + t_u + \text{裕度} $$`

## 7.1 变压器保护

- **纵差理想变比**
  - 可读写法：`nTA1 · nTA2 = nT`
  - LaTeX：`$$ n_{TA1} \cdot n_{TA2} = n_T $$`
- **变比误差**
  - 可读写法：`Δn = |(nTA1/nTA2)/nT - 1|`
  - LaTeX：`$$ \Delta n = \left| \frac{n_{TA1}/n_{TA2}}{n_T} - 1 \right| $$`
- **最大磁通（涌流机理）**
  - 可读写法：`Φmax = 2Φm + Φsy（磁通不能突变 + 剩磁）`
  - LaTeX：`$$ \Phi_{max} = 2\Phi_m + \Phi_{sy} $$`
- **比率差动判据**
  - 可读写法：`Id = |İ1' + İ2'| > Iop.min 且 Id > K·Ires + Iop.min，Ires = max(|I1'|,|I2'|) 或 |İ1'-İ2'|/2`
  - LaTeX：`$$ I_d = |\dot{I}_1'+\dot{I}_2'| > K I_{res} + I_{op.min} $$`
- **二次谐波制动**
  - 可读写法：`二次谐波幅值/基波幅值 ≥ 15% 时闭锁差动`
  - LaTeX：`$$ \frac{I_{2\omega}}{I_{1\omega}} \ge 15\% \Rightarrow \text{闭锁差动} $$`
- **复合电压启动**
  - 可读写法：`负序过电压 U2.op = (0.06～0.12)UN`
  - LaTeX：`$$ U_{2.op} = (0.06 \sim 0.12) U_N $$`
